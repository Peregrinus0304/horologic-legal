Contact

Email ticklog.support@dontsp.am. We read this inbox for support, privacy requests, and App Store questions.

Common questions

  • Live measurement needs the microphone — TickLog asks only when you start listening. If you denied access, enable it in iOS Settings → TickLog → Microphone. You can still analyse an audio file without the mic.
  • Weak or noisy signal — quiet room, crown a few centimetres from the mic, set the correct lift angle / movement.
  • Library disappeared after delete/reinstall — data is stored on the device, not in a TickLog account. Restore from an iPhone backup if you have one. TickLog Pro still restores via Apple ID.
  • Unlock / Restore Pro — purchases go through Apple. Use Restore Purchase in Settings or on the paywall, signed in with the Apple ID that bought Pro.
  • Billing or refund — request through Apple (report a problem / purchase history). TickLog cannot refund an App Store charge directly.
